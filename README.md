## 🚀 Featured Projects

### ◆ Aira Photobooth System ⭐ *Latest*
> `Python · AI-Powered Desktop Application · April 2026`

A Windows desktop application written in **Python** that automates the **end-to-end photobooth workflow** for freelance photographers. Connects directly to a **Canon EOS DSLR via USB tethered capture**, composites shots into pre-designed event frames in under 3 seconds, manages session records and payments, and delivers print-ready output — all without manual file transfers, Photoshop, or repetitive copy-paste tasks.

Runs two independent windows: an **Operator Dashboard** and a **Viewer Dashboard** extended to a second monitor or TV, giving clients a live camera preview and their final framed result in real time. Sessions are saved to a local **SQLite database** with full payment tracking in **Philippine Peso (PHP)**. Guests can save photos to a personal USB flash drive.

**Stack:** `Python` `SQLite` `Canon EOS USB Tethering` `Image Compositing`  
**Role:** 💻 Solo Developer  
**Highlights:** `Live DSLR Preview` · `Auto Frame Compositing` · `Payment Tracking` · `USB Export` · `Dual Monitor UI`
